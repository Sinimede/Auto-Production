# Design: D17 Notation Fix for 45×90 Aluminium Profiles

**Date:** 2026-03-17
**Status:** Approved

---

## Problem

The D17 capping-end detection fails for 45×90 aluminium profiles in two ways:

1. **Wrong body length**: `_detect_capped_ends` uses `max(bbox_extents)` to determine the body's length. For a short 45×90 piece (length < 90 mm), the cross-section height (90 mm) is larger than the length → wrong length → body never matched to a cut list item → D17 not computed.

2. **Wrong axis**: `_match_body_to_direction` uses `argmax(extents)` as fallback (SW 2024 weldments never expose standalone sketch features). Same root cause — argmax picks the 90 mm cross-section axis instead of the actual length axis.

3. **Missing holes-per-end logic**: Even when detection works correctly, the current code assumes 1 hole per capped end (valid for 45×45 only). A 45×90 profile needs 2 holes per capped end, with a different notation format.

---

## Scope

- Fix body length detection and axis selection for all profiles, including short 45×90 pieces.
- Add cross-section classification to determine holes-per-end.
- Update D17 suffix generation accordingly.
- Emit "VERIFICAR FURAÇÕES" for unknown cross-sections with capped ends.
- No changes to capping detection geometry (bbox containment stays as-is).
- No attempt to read WeldMemberFeat sketch direction (deferred to future).

---

## Architecture

### 1. New helper: `_select_length_axis` (in `solidworks.py`)

```python
def _select_length_axis(extents_mm: list, raw_items: list) -> tuple:
    """
    Given 3 bbox extents (mm) and a list of CutListItem, find the axis
    whose extent matches an item length within LENGTH_MATCH_TOLERANCE_MM.

    Returns (axis_idx, length_mm, cross_dims_mm) where:
      - axis_idx:      0, 1, or 2 (X, Y, Z)
      - length_mm:     the matched extent value
      - cross_dims_mm: sorted [dim_short, dim_long] of the two remaining axes

    Returns (None, None, None) if no axis matches any item length.

    Tiebreak: if multiple axes match, picks the axis with the largest extent.
    This is conservative — profiles are typically longer than their cross-section,
    so the largest matching extent is the length axis. In the unlikely case two
    axes match different items at the same length, the largest extent still wins.
    """
```

This helper is the single fix point for both bugs. It replaces:
- `max(extents) * 1000` in `_detect_capped_ends`
- `argmax(extents)` in `_match_body_to_direction` fallback

Both new helpers follow the existing `_` private naming convention and are imported
directly by name in tests: `from solidworks import _select_length_axis`.

### 2. New helper: `_classify_profile_holes` (in `solidworks.py`)

```python
def _classify_profile_holes(cross_dims_mm: list) -> int | str:
    """
    Given sorted [dim_short, dim_long] cross-section dims (mm), return:
      1            for 45×45  (both dims in 40–50 mm range)
      2            for 45×90  (short dim 40–50 mm, long dim 85–95 mm)
      "VERIFICAR"  for anything else
    """
```

Tolerance: ±5 mm around nominal dimensions (40–50 mm for 45, 85–95 mm for 90).

### 3. Updated `_detect_capped_ends` return value (in `solidworks.py`)

**Breaking change** — currently returns `(item_caps, warnings)` (2-tuple).
After fix returns `(item_caps, item_cross_dims, warnings)` (3-tuple).

```
item_cross_dims: dict[item_idx → list[cross_dims_mm]]
```

One `cross_dims_mm` entry per body in that item group. All bodies for the same
item share the same cross-section; the caller uses `item_cross_dims[i][0]`.

**Migration — all 7 call sites must be updated:**

| Location | Current | After |
|----------|---------|-------|
| `solidworks.py:1036` | `item_caps, cap_warns = _detect_capped_ends(...)` | `item_caps, item_cross_dims, cap_warns = _detect_capped_ends(...)` |
| `test_solidworks_helpers.py` — 6 test unpacks of the form `item_caps, _ = _detect_capped_ends(...)` | `item_caps, _cross, _ = _detect_capped_ends(...)` |

### 4. Updated D17 suffix generation (in `solidworks.py`, inside `get_weldment_cut_list`)

The suffix dict at line 1049 is replaced with a call to `_d17_suffix(capped, holes_per_end)`.

`holes_per_end` is derived by:
1. Looking up `item_cross_dims.get(i)` — if absent or empty, use `"VERIFICAR"` as fallback.
2. Calling `_classify_profile_holes(item_cross_dims[i][0])`.

```python
def _d17_suffix(capped_ends: int, holes_per_end) -> str:
    """
    Returns the D17 annotation suffix for a given (capped_ends, holes_per_end).
    holes_per_end is 1, 2, or "VERIFICAR".
    """
```

| capped_ends | holes_per_end | suffix |
|-------------|---------------|--------|
| 0 | any | `""` |
| 1 | 1 | `" D17"` |
| 2 | 1 | `" D17/D17"` |
| 1 | 2 | `" D17/D17/-/-"` |
| 2 | 2 | `" D17/D17/D17/D17"` |
| any (>0) | `"VERIFICAR"` | `" VERIFICAR FURAÇÕES"` |

## Data Flow

```
get_weldment_cut_list(sw, part_path)  [solidworks.py]
  │
  ├── _detect_capped_ends(all_bodies, items, sketch_lines, part_path)
  │     │
  │     └── per body: _select_length_axis(extents_mm, raw_items)
  │           → (axis_idx, length_mm, cross_dims_mm)
  │
  │   returns (item_caps, item_cross_dims, cap_warns)
  │
  └── expansion loop (solidworks.py lines ~1040–1055):
        for each item_i:
          capped     = aggregate(item_caps[i])
          cross_dims = item_cross_dims.get(i, [[]])[0]  ← fallback to [] if absent
          holes_per_end = _classify_profile_holes(cross_dims) if cross_dims else "VERIFICAR"
          suffix     = _d17_suffix(capped, holes_per_end)
```

---

## Error Handling

- Body with no matching axis → treated as tampo (no item assigned), warning emitted. Same as current behaviour.
- Item with no bodies (all unmatched) → capped=0, no suffix. Same as current.
- Item with `item_caps` entries but absent `item_cross_dims` → `holes_per_end = "VERIFICAR"`, capped > 0 → suffix `" VERIFICAR FURAÇÕES"`.
- Unknown cross-section with capped ends → suffix `" VERIFICAR FURAÇÕES"`.
- Unknown cross-section with no capped ends (capped=0) → suffix `""` (no holes, no note needed).

## Testing

### `_select_length_axis` (unit tests, no SW required)
- 45×45, length 200 mm → correct axis, cross_dims `[45, 45]`
- 45×90, length 150 mm → correct axis, cross_dims `[45, 90]`
- 45×90, length **80 mm** (critical: length < cross-section height) → axis picks 80 mm, not 90 mm
- No matching axis → `(None, None, None)`
- Two axes match same item length → picks largest extent

### `_classify_profile_holes` (unit tests)
- `[45, 45]` → `1`
- `[45, 90]` → `2`
- `[30, 60]` → `"VERIFICAR"`
- `[44, 91]` (within tolerance) → `2`

### `_detect_capped_ends` (unit tests, extended)
- All existing tests updated to unpack 3-tuple: `item_caps, _cross, warns = _detect_capped_ends(...)`
- New: 45×90 body (length 150 mm), 1 capped end → `item_cross_dims[0] = [[45.0, 90.0]]`
- New: 45×90 body (length 150 mm), 2 capped ends → same cross_dims
- New: **short 45×90 body (length 80 mm, cross-section 90 mm)** — bbox extents [0.045, 0.08, 0.09] m, item length 80 mm — asserts body IS matched to item (axis_idx picks 80 mm extent, not 90 mm)

### `_d17_suffix` (unit tests)
- `(0, 1)` → `""`
- `(1, 1)` → `" D17"`
- `(2, 1)` → `" D17/D17"`
- `(1, 2)` → `" D17/D17/-/-"`
- `(2, 2)` → `" D17/D17/D17/D17"`
- `(1, "VERIFICAR")` → `" VERIFICAR FURAÇÕES"`
- `(0, "VERIFICAR")` → `""`
